## Project Overview
The **Netflix Content Success Analytics Engine** demonstrates a complete data‑science workflow:
- Load the public `netflix_titles.csv` catalog.
- Perform advanced feature engineering (content age, genre count, country count, director flags, numeric duration, etc.).
- Construct a *success‑potential* proxy target by weighting recentness, genre diversity, country diversity, director availability and duration.
- Split the data (80/20 stratified) and preprocess with one‑hot encoding and standard scaling.
- Train three classifiers – Logistic Regression, Random Forest, Gradient Boosting – and compare them on accuracy, precision, recall and F1‑score.
- Automatically generate business‑oriented insights and eight visual dashboards.
- Provide a lightweight command‑line script (`scripts/movie_vs_tv_show_classification.py`) for a quick Movie vs TV‑Show classification task.

The repository is intentionally lightweight: the core logic lives in Jupyter notebooks under `notebooks/` and the entry‑point script under `scripts/`. The package itself (`src/netflix_content_recommendation_system`) currently contains a placeholder CLI that prints a greeting.

## Dataset
- **File:** `Data/netflix_titles.csv`
- **Source:** Public Netflix title dataset (often shared on Kaggle). It contains 8,790 records and 10 columns:
  - `show_id` – Unique identifier
  - `type` – "Movie" or "TV Show"
  - `title`
  - `director`
  - `country`
  - `date_added`
  - `release_year`
  - `rating`
  - `duration`
  - `listed_in` – Pipe‑separated genre list

The notebook **`Netflix_Content_Success.ipynb`** loads this CSV, inspects basic statistics (row count, column types, missing values) and prints a preview of the first five rows.

## Installation & Setup
The project uses **Python 3.11** (see `.python-version`). Dependencies are declared in `pyproject.toml` and can be installed with the lightweight `uv` tool or with `pip`.

```bash
# If you do not have uv installed
pip install uv

# Install the project in editable mode (includes the placeholder package)
uv venv   # creates a virtual environment in .venv
uv pip install -e .
```

Alternatively, using pip directly:
```bash
python -m venv .venv
source .venv/bin/activate  # on Windows: .venv\Scripts\activate
pip install -r <(uv pip compile --no-build-isolation pyproject.toml)  # generates a temporary requirements list
```

## Usage
### Running the full analytics notebook
```bash
# Launch Jupyter (or VS Code Jupyter view)
uv run jupyter notebook notebooks/Netflix_Content_Success.ipynb
```
The notebook walks through every step – data loading, feature engineering, proxy target creation, train/test split, preprocessing, model training, evaluation, and automated insight generation.

### Quick Movie‑vs‑TV‑Show classification script
```bash
python scripts/movie_vs_tv_show_classification.py
```
The script:
1. Loads the same CSV.
2. Encodes the `type` column as a binary label.
3. Performs minimal preprocessing (numeric duration, year extraction, simple director flags).
4. Trains three models (Logistic Regression, Decision Tree, Random Forest).
5. Prints each model’s accuracy, precision, recall and F1‑score, then stores a CSV comparison in `results/model_comparison.csv`.

## Feature Engineering
Key engineered columns (see notebook cells) include:
- `content_age` – Current year (2026) minus `release_year`.
- `country_count` – Number of countries listed.
- `genre_count` – Number of genres listed.
- `has_director` / `director_count` – Presence and count of directors.
- `duration_value` – Extracted numeric minutes/season count.
- `movie_duration` & `tv_show_seasons` – Conditional numeric duration.
- `release_decade` – Rounded decade of release.
- `is_recent_content` – Flag for titles released in or after 2015.

These features feed both the proxy‑target construction and the classification models.

## Modeling & Evaluation
Three classifiers are trained on the engineered feature matrix:
| Model                | Accuracy | Precision | Recall | F1‑Score |
|----------------------|----------|-----------|--------|----------|
| Logistic Regression  | 0.9937   | 0.9977    | 0.9898 | 0.9937   |
| Random Forest        | **0.9977** | **0.9989** | **0.9966** | **0.9977** |
| Gradient Boosting    | 0.9943   | 0.9989    | 0.9898 | 0.9943   |

*Random Forest achieved the highest F1‑score (0.9977).*  All models perform exceptionally well because the proxy target is built from the same engineered features – a point noted in the limitations section.

## Key Results & Insights
The notebook automatically prints a concise business summary (see the final cells). Highlights:
- **Dataset size:** 8,790 titles (69.7 % movies, 30.3 % TV shows).
- **Success‑potential split:** 50 % high, 50 % low (median threshold).
- **Higher‑potential titles** have on average **2.83 genres** vs **1.56** for lower‑potential titles and a **76 % recent‑content rate** vs **65 %**.
- **Top genre** among high‑potential titles with ≥ 50 titles: **TV Mysteries** (≈ 99 % high‑potential rate).
- **Peak production year:** 2018 with 1,146 titles.
- **Best model:** Random Forest (F1 = 0.9977).

## Limitations & Future Work
- The **success‑potential target** is a *proxy* built from content attributes; the dataset lacks true performance metrics (views, watch time, revenue, user ratings). Consequently, the high model scores reflect target leakage rather than genuine predictive power.
- Future iterations should integrate real audience data (e.g., view counts from a streaming platform) to create a validated outcome variable.
- The placeholder package (`src/…/__init__.py`) can be expanded into a reusable CLI or library.
- Dependency typo: `panadas` in `pyproject.toml` should be `pandas`. Correcting it will prevent installation errors.
